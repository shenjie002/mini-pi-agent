# Agent Loop
Agent loop is a fundamental concept in reinforcement learning and multi-agent systems. It involves the continuous interaction between agents and their environment, where actions are taken, their outcomes observed, and feedback provided to guide future decisions.

## Key Components
- **Agents**: The entities that perform actions within the environment.
- **Environment**: The setting or scenario where the agents operate and interact.
- **Actions**: The choices made by agents to influence the environment.
- **Observations**: The feedback received from the environment after an action is taken.
- **Rewards/Penalties**: The reinforcement signal that informs the agent of its performance.

## Cycle
1. An agent selects and executes actions in the environment based on its current policy or strategy.
2. The environment reacts to these actions, producing new observations and possibly changing states.
3. The agent receives feedback in the form of rewards or penalties.
4. This process repeats iteratively as the loop continues.
